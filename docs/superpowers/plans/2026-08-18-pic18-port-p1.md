# PIC18 Port P1 (Encoder + Simulator Core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the workspace a PIC18 assembler encoder (`asm`) and a PIC18 simulator core (`sim`), for the PIC18F4550, from hand-written `.asm` source only — no codegen from IR in this phase. Every instruction's encoding is byte-for-byte verified against `gpasm -p p18f4550`, and every instruction's execution is verified in the new simulator.

**Architecture:** `asm` gains a second top-level encoder, `assemble_pic18`, alongside the existing `assemble` (PIC14) — not a shared generic function. `assemble_file_to_hex` (already `&Device`-aware since P0) dispatches on `device.core`. Same shape in `sim`: a new `Pic18` struct alongside `Pic14`, sharing nothing but the crate and (with a size argument) the Intel-HEX decoder. This mirrors the already-approved D-1 decision for `isel`/`isel-pic18` (docs/29 §2): the two instruction sets are different enough that sharing code would produce a leaky abstraction, and PIC14's existing code must never be put at risk by a PIC18 edit.

**Tech Stack:** Rust, Cargo workspace, `nix develop` dev shell. `gpasm` (gputils 1.5.2, already in the dev shell) is the verification oracle — every encoding in this plan was derived by assembling probe `.asm` files with `gpasm -p p18f4550` and reading back the resulting Intel HEX, not from a datasheet (none is available locally; see "Where the data came from" below).

**Spec:** [`docs/29-pic18-port-design.md`](../../29-pic18-port-design.md) — §4's P1 row ("PIC18 `asm` encoder and `sim` core. Hand-written `.asm` inputs only, no codegen." / acceptance: "`gpasm -p p18f4550` byte-for-byte HEX match, plus simulator tests per instruction group.") and §2 D-4 (standard instruction set only, `XINST` stays off).

## Where the data came from

No PIC18 datasheet (DS39632) is available in this environment. Every fact in this plan instead comes from one of two places, both already-sanctioned project techniques (docs/08, "gputils... is a useful oracle and device-data source"; docs/05-verification.md's whole-program philosophy of treating an external assembler as ground truth):

1. **Empirical derivation via `gpasm`.** Every instruction's encoding below was obtained by writing a probe `.asm` line, assembling it with `nix develop --command gpasm -p p18f4550 <file>`, and reading the resulting Intel HEX back into 16-bit words — the exact same oracle P1's own acceptance criterion requires a match against. Each field (the `d`/`a`/`b` bits, the `f`/`k`/`n` operands) was isolated by varying it independently across multiple probes and diffing the resulting words, not assumed from general knowledge.
2. **gputils' own shipped device-data files**, read directly (no assembly needed): `/nix/store/58q5xhvb6b31vpn0wgpcsha3ggfpc986-gputils-1.5.2/share/gputils/header/p18f4550.inc` (SFR addresses), `.../lkr/18f4550_g.lkr` (memory map), and the four `PIC18F4550-*.html` pages in `.../share/doc/gputils-1.5.2/html/` (flash size, RAM layout, access-bank boundary). These paths may differ if gputils is reinstalled at a different version; `nix develop --command gpasm --version` reports the version, and `find /nix/store -maxdepth 1 -iname '*gputils*'` re-locates the store path if needed.

**Two facts are NOT independently verified this way** and are instead well-known, stable PIC18-family architecture constants (unchanged across the whole PIC18 line since its introduction, and required for the instruction encodings above to even make sense): the **31-level hardware call stack** and the **two interrupt vectors at byte addresses `0x000008` (high priority) and `0x000018` (low priority)**. If a datasheet or reference manual becomes available before this plan is executed, confirm these two figures against it first; otherwise proceed — nothing else in this plan depends on unverified data.

## Global Constraints

- **Standard instruction set only.** The extended instruction set (`XINST`) is out of scope per docs/29 §2 D-4 — do not implement `ADDFSR`/`ADDULNK`/`CALLW`/`MOVSF`/`MOVSS`/`PUSHL`/`SUBFSR`/`SUBULNK`.
- **No codegen in this phase.** Nothing in `isel`/`alloc`/`banking`/`legalize` changes. Every test in this plan hand-writes `.asm` source directly.
- **PIC14 must never regress.** `assemble` (PIC14) and `Pic14` keep their exact current signatures — this plan never edits their code, only adds new functions/types alongside them. The full existing test suite (`cargo test --workspace`) must stay green after every task.
- **PIC18-core-architecture facts stay hard-coded in the encoder/sim, not `Device` fields** — mirroring how PIC14's RP0/RP1 bit positions and the 7-bit bank mask already work. The access-bank split (`0x000–0x05F` and `0xF60–0xFFF`), the `BSR`-based banking scheme, and the STATUS register's bit layout (`C`=0, `DC`=1, `Z`=2, `OV`=3, `N`=4) are the same for every PIC18 device in the family, not a per-part fact the way RAM/flash size are — so they are not added to the `Device` struct. Only `flash_words` (varies by part, e.g. the 2455/2550 have less) belongs on `Device`.
- Conventional commits, single line, at most 3 lines (project convention). Branch: `feat/pic18-p1-encoder-and-sim` (already created, forked from master with P0 merged).

## Reference: the complete PIC18F4550 instruction encoding table

This is the full data set every encoder/sim task pulls from. `f` = 8-bit file offset, `a` = access bit (0 = access bank, 1 = BSR-banked — **always written explicitly by our encoder; the bare/inferred forms gpasm also accepts are not supported**, matching this codebase's existing PIC14 encoder convention of never inferring an operand), `d` = destination select (0 = W, 1 = f), `b` = 3-bit bit number, `k` = literal, `n` = signed word-offset (branches) or word address (`GOTO`/`CALL`/`LFSR`/`MOVFF`).

### Conditional relative branches — 8-bit signed word offset, 1 word

| Mnemonic | Encoding |
|---|---|
| BZ | `0xE000 \| n8` |
| BNZ | `0xE100 \| n8` |
| BC | `0xE200 \| n8` |
| BNC | `0xE300 \| n8` |

| BNOV | `0xE500 \| n8` |
| BN | `0xE600 \| n8` |

`n8 = (target_word - (this_word + 1)) as i8 as u8` — two's complement, ±128 words, verified both directions (`0xE207` forward-7, `0xE3F7` backward-9).

### Unconditional relative branches — 11-bit signed word offset, 1 word

| Mnemonic | Encoding |
|---|---|
| BRA | `0xD000 \| (n11 & 0x7FF)` |
| RCALL | `0xD800 \| (n11 & 0x7FF)` |

`n11 = target_word - (this_word + 1)`, two's complement, ±1024 words. Verified: offset −2 → `0xD7FE`, offset −4 → `0xDFFC`.

### Two-word absolute (21-bit target, **word** address = byte address ÷ 2)

| Mnemonic | Word 1 | Word 2 |
|---|---|---|
| GOTO | `0xEF00 \| (k & 0xFF)` | `0xF000 \| ((k>>8) & 0xFFF)` |
| CALL | `0xEC00 \| s<<8 \| (k & 0xFF)` | `0xF000 \| ((k>>8) & 0xFFF)` |

`k = target_byte_addr >> 1`. Verified: `GOTO 0x1234` → `0xEF1A 0xF009` (`k = 0x1234/2 = 0x91A`); `CALL 0x1234` (`s=0`, normal) → `0xEC1A 0xF009`; `CALL 0x1234,FAST` (`s=1`, fast call — saves WREG/STATUS/BSR to a shadow) → `0xED1A 0xF009`. Note `s` is **bit 8 of word 1**, unlike `RETURN`/`RETFIE` where the fast bit is bit 0.

### LFSR — loads a 12-bit literal into FSR0/1/2, two words

Word 1: `0xEE00 | (fsr<<4) | ((k>>8) & 0xF)`. Word 2: `0xF000 | (k & 0xFF)`. `fsr` = 0/1/2. Verified: `LFSR 2, 0xFFF` → `0xEE2F 0xF0FF`.

### MOVFF — full 12-bit source and destination, no access bit, two words

Word 1: `0xC000 | (src & 0xFFF)`. Word 2: `0xF000 | (dst & 0xFFF)`. Verified: `MOVFF 0x55, 0xF80` → `0xC055 0xFF80`. Both operands are raw 12-bit addresses — no access-bank inference needed, works across the whole data space.

## Reference: the access-bank / BSR addressing model (core PIC18 architecture, not device-specific)

Every byte/bit-oriented instruction's `f` operand plus its `a` bit resolve to a physical 12-bit address:

- **`a=0` (access bank):** if `f <= 0x5F`, physical = `f` (the low GPR access window `0x000-0x05F`). If `f > 0x5F`, physical = `0xF00 + f` (the high SFR access window `0xF60-0xFFF` — e.g. `f=0x60` → `0xF60`, `f=0xFF` → `0xFFF`).
- **`a=1` (banked):** physical = `(BSR << 8) | f`, where `BSR` (the SFR at `0xFE0`) was last set by `MOVLB`.

This is identical for every PIC18 device (verified empirically against `p18f4550`; it does not appear in the RAM-bank-count table, which only varies the *implemented* GPR extent, not this addressing scheme) — hence it is hard-coded directly in the `Pic18` simulator's addressing helpers, exactly the way `Pic14`'s `bank_base()` hard-codes the RP1:RP0 formula rather than consulting `Device`.

```rust
/// Word count of one PIC18 instruction line's mnemonic — 2 for the
/// two-word forms (`GOTO`/`CALL`/`LFSR`/`MOVFF`), 1 for everything else.
/// Directives never reach this (handled in `assemble_pic18`'s pass 1
/// before this is called).
fn instruction_words_pic18(line: &str) -> usize {
    let mne = line.split_whitespace().next().unwrap_or("");
    match mne.to_ascii_uppercase().as_str() {
        "GOTO" | "CALL" | "LFSR" | "MOVFF" => 2,
        _ => 1,
    }
}

/// Assemble PIC18 assembly source into 16-bit words indexed by word
/// address. Two-pass like `assemble`: pass 1 resolves labels/`org`/`equ`
/// and measures each line's word count (1 or 2); pass 2 encodes. No
/// `.align`/`.table` — P1 has no const-table codegen to emit them (that
/// machinery arrives with `TBLRD` support in a later phase).
pub fn assemble_pic18(src: &str) -> Vec<u16> {
    let mut symbols: std::collections::HashMap<String, usize> = std::collections::HashMap::new();
    let mut org = 0usize;
    let mut lines: Vec<(usize, String)> = Vec::new();
    for raw in src.lines() {
        let line = raw.split(';').next().unwrap_or("").trim();
        if line.is_empty() {
            continue;
        }
        if line.starts_with("list") || line.starts_with("radix") {
            continue;
        }
        if let Some(rest) = line.strip_prefix("org ") {
            let target = parse_num(rest.trim());
            assert!(
                target >= org,
                "asm: backward .org to 0x{target:04X} from 0x{org:04X} — an .org can only pad forward"
            );
            org = target;
            continue;
        }
        if line.strip_prefix("end").is_some() {
            break;
        }
        if let Some(label) = line.strip_suffix(':') {
            symbols.insert(label.trim().to_string(), org);
            continue;
        }
        if let Some(eq) = line.find(" equ ") {
            let (name, val) = line.split_at(eq);
            symbols.insert(name.trim().to_string(), parse_num(val[" equ ".len()..].trim()));
            continue;
        }
        let words = instruction_words_pic18(line);
        lines.push((org, line.to_string()));
        org += words;
    }
    let mut out = vec![0u16; org];
    for (addr, line) in &lines {
        let encoded = encode_pic18(line, &symbols);
        out[*addr] = encoded[0];
        if encoded.len() == 2 {
            out[*addr + 1] = encoded[1];
        }
    }
    out
}
```

```rust
/// Parse a PIC18 byte/bit-oriented operand tail after the mnemonic:
/// `f[, W|F][, A|B]` or `f, b[, A|B]` (bit-oriented passes `has_bit_field`
/// so the second comma-separated token is a bit number 0-7, not `W`/`F`).
/// Returns `(f, d_or_b, a)`; `d`/`b` and `a` default to 0 when the operand
/// is omitted (mirrors this encoder's explicit-only convention — omission
/// is only for instructions that genuinely have no such field, e.g. the
/// no-`d` group calls this with `has_bit_field = false` and ignores the
/// returned middle value).
fn parse_f_field(rest: &str, symbols: &std::collections::HashMap<String, usize>) -> u16 {
    let f = parse_lit(rest.split(',').next().unwrap().trim(), symbols);
    (f & 0xFF) as u16
}

fn parse_a_bit(rest: &str) -> u16 {
    match rest.to_ascii_uppercase().as_str() {
        "A" => 0,
        "B" => 1,
        other => panic!("asm(pic18): expected A or B, got {other}"),
    }
}

fn parse_d_bit(rest: &str) -> u16 {
    match rest.to_ascii_uppercase().as_str() {
        "W" => 0,
        "F" => 1,
        other => panic!("asm(pic18): expected W or F, got {other}"),
    }
}
```

```rust
/// Decode Intel HEX into 16-bit words for a PIC18F4550-sized program
/// (`0x4000` words = 32768 bytes of flash). Same wire format as
/// `parse_hex` (`asm::to_hex` emits identical HEX regardless of core), just
/// sized for PIC18's larger flash.
pub fn parse_hex_pic18(data: &str) -> Vec<u16> {
    let mut words = vec![0u16; 0x4000];
    for line in data.lines() {
        let line = line.trim();
        if line.is_empty() {
            continue;
        }
        assert!(line.starts_with(':'), "not Intel HEX: {line}");
        let bytes = hex_decode(&line[1..]);
        let len = bytes[0] as usize;
        let addr = ((bytes[1] as usize) << 8) | (bytes[2] as usize);
        let rectype = bytes[3];
        let data = &bytes[4..4 + len];
        match rectype {
            0x00 => {
                for (i, chunk) in data.chunks(2).enumerate() {
                    let w = (chunk[0] as u16) | ((chunk[1] as u16) << 8);
                    words[addr / 2 + i] = w;
                }
            }
            0x01 => break,
            0x04 => {}
            other => panic!("unsupported HEX record type {other:#x}"),
        }
    }
    words
}

/// PIC18F4550 (16-bit-word core) instruction-set simulator. `pc` is a
/// **byte** address (PIC18's PC natively counts bytes, incrementing by 2
/// per one-word instruction), unlike `Pic14::pc` which is a word address —
/// this matches the real hardware and lets the interrupt vectors
/// (0x000008/0x000018) and `GOTO`/`CALL`'s encoded targets be used
/// directly without a unit conversion at every call site.
pub struct Pic18 {
    prog: Vec<u16>,
    ram: [u8; 4096],
    w: u8,
    pc: u32,
    /// Hardware call stack: up to 31 return byte-addresses. `TOSU`/`TOSH`/
    /// `TOSL`/`STKPTR` (SFRs 0xFFF/0xFFE/0xFFD/0xFFC) are computed views
    /// over this, not separate storage — mirrors how `Pic14::read_f`
    /// special-cases the `PCL` SFR address over the `pc` field instead of
    /// storing it twice.
    stack: Vec<u32>,
    halted: bool,
}

impl Pic18 {
    pub fn new(prog: Vec<u16>) -> Self {
        Pic18 { prog, ram: [0; 4096], w: 0, pc: 0, stack: Vec::new(), halted: false }
    }
    pub fn ram(&self) -> &[u8; 4096] {
        &self.ram
    }
    pub fn ram_mut(&mut self) -> &mut [u8; 4096] {
        &mut self.ram
    }
    pub fn w(&self) -> u8 {
        self.w
    }
    pub fn pc(&self) -> u32 {
        self.pc
    }
    pub fn halted(&self) -> bool {
        self.halted
    }
    pub fn run(&mut self, max_steps: usize) -> usize {
        let mut steps = 0;
        while !self.halted && steps < max_steps {
            self.step();
            steps += 1;
        }
        steps
    }
    pub fn step(&mut self) {
        let word = self.prog[(self.pc / 2) as usize];
        // Every recognized opcode is added task-by-task from here; a
        // program of just NOPs already exercises the fetch/pc-advance
        // loop end-to-end.
        if word == 0x0000 {
            self.pc += 2;
        } else {
            panic!("sim(pic18): opcode {word:#06x} not yet implemented");
        }
        if (self.pc / 2) as usize >= self.prog.len() {
            self.halted = true;
        }
    }

    /// Resolve a byte/bit-oriented `(a, f)` pair to its physical 12-bit
    /// address. `a=0` (access bank): `f<=0x5F` -> `f` (low access,
    /// `0x000-0x05F`); `f>0x5F` -> `0xF00+f` (high access/SFR,
    /// `0xF60-0xFFF`). `a=1` (banked): `(BSR<<8)|f`. This split is a core
    /// PIC18 architecture invariant (see the plan's reference section),
    /// hard-coded here exactly as `Pic14::bank_base` hard-codes RP1:RP0.
    fn resolve_f(&self, a: u16, f: u16) -> usize {
        if a == 0 {
            if f <= 0x5F {
                f as usize
            } else {
                0xF00 + f as usize
            }
        } else {
            ((self.ram[0xFE0] as usize) << 8) | f as usize
        }
    }
    fn read_f(&self, a: u16, f: u16) -> u8 {
        self.ram[self.resolve_f(a, f)]
    }
    fn write_f(&mut self, a: u16, f: u16, v: u8) {
        let addr = self.resolve_f(a, f);
        self.ram[addr] = v;
    }
    fn write_d(&mut self, d: u16, a: u16, f: u16, r: u8) {
        if d == 1 {
            self.write_f(a, f, r);
        } else {
            self.w = r;
        }
    }
}
```

Extend `step`'s dispatch to route byte-oriented opcodes to a new `exec_byte`. **The literal range (`0x0800..=0x0FFF`) is a numeric subset of the byte-oriented range (`0x0200..=0x6FFF`)** — Task 14 adds a `_ if (0x0800..=0x0FFF)` arm later, so it MUST be checked before the wider byte-oriented range or it will never be reached; add it now (even though `exec_literal` doesn't exist until Task 14) as a forward-declared arm calling a stub, to fix the ordering once and never revisit it:

```rust
    pub fn step(&mut self) {
        let word = self.prog[(self.pc / 2) as usize];
        let pc = self.pc;
        let next = match word {
            0x0000 => pc + 2,
            0x0004..=0x0007 | 0x0010..=0x0013 | 0x0003 | 0x00FF | 0x0100..=0x010F => {
                panic!("sim(pic18): control/special opcode {word:#06x} not yet implemented (Task 14/16)")
            }
            // MUST come before the byte-oriented arm below — 0x0800..=0x0FFF
            // is numerically inside 0x0200..=0x6FFF, so this order is load
            // bearing, not cosmetic. `exec_literal` panics with a clear
            // "not implemented" until Task 14 replaces this arm's body.
            _ if (0x0800..=0x0FFF).contains(&word) => {
                panic!("sim(pic18): literal opcode {word:#06x} not yet implemented (Task 14)")
            }
            _ if (0x0200..=0x6FFF).contains(&word) => self.exec_byte(pc, word),
            _ => panic!("sim(pic18): opcode {word:#06x} not yet implemented"),
        };
        self.pc = next;
        if (self.pc / 2) as usize >= self.prog.len() {
            self.halted = true;
        }

    /// Byte-oriented dispatch: mask off the variable fields and match the
    /// fixed "base" bits directly against the Reference table's hex
    /// constants — **do not** try to recover an opcode via shift-then-mask
    /// arithmetic (e.g. `(word >> 10) & 0xF`); the two groups have
    /// different-width fixed fields (the d+a+f group's fixed bits are
    /// `word & 0xFC00`, clearing d=bit9/a=bit8/f=bits7-0; the a+f-only
    /// group's fixed bits are `word & 0xFE00`, clearing only a=bit8/f,
    /// because bit9 is part of ITS fixed identifier, not a variable field)
    /// — a narrower mask silently collides unrelated opcodes.
    fn exec_byte(&mut self, pc: u32, word: u16) -> u32 {
        let a = (word >> 8) & 1;
        let d = (word >> 9) & 1;
        let f = word & 0xFF;
        // No-destination-select group first (`word & 0xFE00`): CLRF/
        // CPFSEQ/CPFSGT/CPFSLT/MOVWF/MULWF/NEGF/SETF/TSTFSZ.
        match word & 0xFE00 {
            0x6A00 => {
                // CLRF
                self.write_f(a, f, 0);
                self.set_z(0);
                return pc + 2;
            }
            0x6200 => {
                // CPFSEQ: skip if f == W, no flags
                if self.read_f(a, f) == self.w {
                    return pc + 4;
                }
                return pc + 2;
            }
            _ => {}
        }
        // Destination-select group (`word & 0xFC00`).
        match word & 0xFC00 {
            0x2400 => {
                // ADDWF: f + W
                let fv = self.read_f(a, f);
                let r = fv.wrapping_add(self.w);
                self.add_flags(fv, self.w, r);
                self.set_zn(r);
                self.write_d(d, a, f, r);
            }
            0x5C00 => {
                // SUBWF: f - W
                let fv = self.read_f(a, f);
                let r = fv.wrapping_sub(self.w);
                self.sub_flags(fv, self.w, r);
                self.set_zn(r);
                self.write_d(d, a, f, r);
            }
            0x3800 => {
                // SWAPF: nibble swap, no flags
                let v = self.read_f(a, f);
                let r = (v << 4) | (v >> 4);
                self.write_d(d, a, f, r);
            }
            0x2C00 => {
                // DECFSZ
                let r = self.read_f(a, f).wrapping_sub(1);
                self.write_d(d, a, f, r);
                if r == 0 {
                    return pc + 4; // skip the next (1-word) instruction
                }
            }
            other => panic!("sim(pic18): byte opcode base {other:#06x} (word {word:#06x}) not yet implemented — extend per the Task 3 encoding table"),
        }
        pc + 2
    }
```

```rust
    pub fn step(&mut self) {
        let word = self.prog[(self.pc / 2) as usize];
        let pc = self.pc;
        let top_byte = (word >> 8) as u8;
        let next = match word {
            0x0000 => pc + 2,
            // MUST precede the byte-oriented arm below: 0x0800..=0x0FFF is
            // numerically inside 0x0200..=0x6FFF (see Task 12's note — this
            // ordering is load bearing, not stylistic).
            _ if (0x0800..=0x0FFF).contains(&word) => self.exec_literal(pc, word),
            _ if (0x0200..=0x6FFF).contains(&word) => self.exec_byte(pc, word),
            _ if (0x7000..=0xBFFF).contains(&word) => self.exec_bit(pc, word),
            _ if (0xE000..=0xE7FF).contains(&word) => self.exec_cond_branch(pc, word),
            _ if (0xD000..=0xDFFF).contains(&word) => self.exec_bra_rcall(pc, word),
            0xC000..=0xCFFF => {
                let w2 = self.prog[(pc / 2) as usize + 1];
                self.exec_movff(pc, word, w2)
            }
            0xEC00..=0xEFFF => {
                let w2 = self.prog[(pc / 2) as usize + 1];
                self.exec_goto_call_lfsr(pc, word, w2)
            }
            0x0010 | 0x0011 => self.exec_retfie(pc, word),
            0x0012 | 0x0013 => { self.pop_return() }
            _ => panic!("sim(pic18): opcode {word:#06x} (top byte {top_byte:#04x}) not yet implemented"),
        };
        self.pc = next;
        if (self.pc / 2) as usize >= self.prog.len() {
            self.halted = true;
        }
    }

    fn exec_cond_branch(&mut self, pc: u32, word: u16) -> u32 {
        let cond = (word >> 8) & 0x7;
        let n = (word & 0xFF) as i8 as i32;
        let taken = match cond {
            0 => self.read_f(0, 0xD8) & 0x04 != 0, // BZ: Z set
            1 => self.read_f(0, 0xD8) & 0x04 == 0, // BNZ
            2 => self.read_f(0, 0xD8) & 0x01 != 0, // BC
            3 => self.read_f(0, 0xD8) & 0x01 == 0, // BNC
            4 => self.read_f(0, 0xD8) & 0x08 != 0, // BOV
            5 => self.read_f(0, 0xD8) & 0x08 == 0, // BNOV
            6 => self.read_f(0, 0xD8) & 0x10 != 0, // BN
            7 => self.read_f(0, 0xD8) & 0x10 == 0, // BNN
            _ => unreachable!(),
        };
        if taken {
            let next_word = (pc / 2) as i32 + 1 + n;
            (next_word as u32) * 2
        } else {
            pc + 2
        }
    }

    fn exec_bra_rcall(&mut self, pc: u32, word: u16) -> u32 {
        let raw = word & 0x7FF;
        let n = if raw & 0x400 != 0 { (raw as i32) - 0x800 } else { raw as i32 }; // sign-extend 11 bits
        let is_call = word & 0x0800 != 0;
        let next_word = (pc / 2) as i32 + 1 + n;
        if is_call {
            self.push_return(pc + 2);
        }
        (next_word as u32) * 2
    }

    fn exec_goto_call_lfsr(&mut self, pc: u32, word: u16, word2: u16) -> u32 {
        let k12 = (word2 & 0xFFF) as u32;
        match word & 0xFF00 {
            0xEF00 => {
                let k = ((k12 << 8) | (word & 0xFF) as u32) as u32;
                k * 2 // word address -> byte address
            }
            0xEC00 | 0xED00 => {
                let k = (k12 << 8) | (word & 0xFF) as u32;
                self.push_return(pc + 4);
                k * 2
            }
            0xEE00 => {
                let fsr = ((word >> 4) & 0x3) as usize;
                let k = ((word & 0xF) as u16) << 8 | (word2 & 0xFF);
                let (lo_addr, hi_addr) = match fsr {
                    0 => (0xFE9, 0xFEA),
                    1 => (0xFE1, 0xFE2),
                    2 => (0xFD9, 0xFDA),
                    _ => unreachable!(),
                };
                self.ram[lo_addr] = (k & 0xFF) as u8;
                self.ram[hi_addr] = (k >> 8) as u8;
                pc + 4
            }
            _ => panic!("sim(pic18): unrecognized two-word opcode {word:#06x}"),
        }
    }

    fn exec_movff(&mut self, pc: u32, word: u16, word2: u16) -> u32 {
        let src = (word & 0xFFF) as usize;
        let dst = (word2 & 0xFFF) as usize;
        self.ram[dst] = self.ram[src];
        pc + 4
    }

    fn exec_retfie(&mut self, _pc: u32, _word: u16) -> u32 {
        // RETFIE also restores GIE/GIEH from the shadow saved on interrupt
        // entry — no interrupt-entry modelling exists yet in this plan
        // (P1 has no ISR support requirement), so for now RETFIE behaves
        // like RETURN. Revisit when interrupt modelling is added for
        // PIC18 (mirrors Pic14's fire_interrupt/request_interrupt, out of
        // scope for P1).
        self.pop_return()
    }

    fn push_return(&mut self, addr: u32) {
        assert!(self.stack.len() < 31, "sim(pic18): call stack overflow (depth 31)");
        self.stack.push(addr);
    }
    fn pop_return(&mut self) -> u32 {
        self.stack.pop().unwrap_or(0)
    }
```

```rust
            0xFFD => self.stack.last().map(|v| (*v & 0xFF) as u8).unwrap_or(0),
            0xFFE => self.stack.last().map(|v| ((*v >> 8) & 0xFF) as u8).unwrap_or(0),
            0xFFF => self.stack.last().map(|v| ((*v >> 16) & 0xFF) as u8).unwrap_or(0),
            _ => self.ram[addr],
        }
    }
```

```rust
    fn resolve_f(&mut self, a: u16, f: u16) -> usize {
        // Indirect addressing registers: each FSRn is stored across two
        // access-bank bytes (FSRnL/FSRnH); INDFn/POSTINCn/POSTDECn/
        // PREINCn/PLUSWn read/write through it, with the side effects
        // (advance/retreat FSRn) happening here so every caller (read_f,
        // write_f) gets them for free without duplicating the logic.
        let (fsrn_lo, fsrn_hi, indf, postinc, postdec, preinc) = match f {
            0xEF | 0xEE | 0xED | 0xEC | 0xEB => (0xE9, 0xEA, 0xEF, 0xEE, 0xED, 0xEC), // FSR0 group
            0xE7 | 0xE6 | 0xE5 | 0xE4 | 0xE3 => (0xE1, 0xE2, 0xE7, 0xE6, 0xE5, 0xE4), // FSR1 group
            0xDF | 0xDE | 0xDD | 0xDC | 0xDB => (0xD9, 0xDA, 0xDF, 0xDE, 0xDD, 0xDC), // FSR2 group
            _ => return self.resolve_direct(a, f),
        };
        let lo_addr = 0xF00 + fsrn_lo;
        let hi_addr = 0xF00 + fsrn_hi;
        let cur = ((self.ram[hi_addr] as u16) << 8) | self.ram[lo_addr] as u16;
        let write_back = |ram: &mut [u8; 4096], v: u16| {
            ram[lo_addr] = (v & 0xFF) as u8;
            ram[hi_addr] = (v >> 8) as u8;
        };
        match f {
            _ if f == indf => cur as usize,
            _ if f == postinc => {
                write_back(&mut self.ram, cur.wrapping_add(1));
                cur as usize
            }
            _ if f == postdec => {
                write_back(&mut self.ram, cur.wrapping_sub(1));
                cur as usize
            }
            _ if f == preinc => {
                let next = cur.wrapping_add(1);
                write_back(&mut self.ram, next);
                next as usize
            }
            _ => {
                // PLUSWn: cur + (signed W), no side effect on FSRn.
                let offset = self.w as i8 as i32;
                ((cur as i32) + offset) as usize
            }
        }
    }

    /// The plain access-bank/BSR resolution from Task 11, renamed —
    /// `resolve_f` now handles indirect registers first and falls through
    /// to this for everything else.
    fn resolve_direct(&self, a: u16, f: u16) -> usize {
        if a == 0 {
            if f <= 0x5F { f as usize } else { 0xF00 + f as usize }
        } else {
            ((self.ram[0xFE0] as usize) << 8) | f as usize
        }
    }
```
